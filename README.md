# 🎓 Smart Career & Placement Management System (SCPS)

A Complete Web-Based Career & Placement Management System developed using **Core PHP, MySQL, HTML5, CSS3, Bootstrap 5, JavaScript, jQuery, AJAX, Font Awesome, and SweetAlert2**.

This project provides a centralized platform where **Students**, **Companies**, and **Administrators** can efficiently manage the complete placement process.

---

## 📌 Project Overview

The Smart Career & Placement Management System simplifies campus recruitment by connecting students, companies, and administrators on a single platform.

The system allows students to create professional profiles, upload resumes, search and apply for jobs, while companies can post jobs, review applications, and recruit candidates. Administrators manage the entire system including students, companies, jobs, reports, and applications.

# ⚙ Installation

### 1. Clone Repository

```bash
git clone https://github.com/your-username/smart-career-placement-management-system.git
```

---

### 2. Move Project

Copy the project into:

```text
xampp/htdocs/
```

---

### 3. Import Database

Import

```text
database/scps.sql
```

using **phpMyAdmin**.

---

### 4. Configure Database

Open

```text
includes/config.php
```

Update database credentials.

```php
DB_HOST = localhost
DB_USER = root
DB_PASS = ""
DB_NAME = career_placement
```

---

### 5. Run Project

Open

```text
http://localhost/career-placement-system/
```
